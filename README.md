# Swift 数据类型 Demo

## 简介

展示 Swift 中各种基本数据类型：整数、浮点、布尔、字符串、字符、元组。

## 基本原理

Swift 是强类型语言，提供丰富的内置类型。

## 启动和使用

```bash
cd swift-data-types-demo
swift run
```

## 教程

### 整数类型

- `Int8`, `Int16`, `Int32`, `Int64`: 有符号整数
- `UInt8`, `UInt16`, `UInt32`, `UInt64`: 无符号整数
- `Int`: 平台相关（64位）

### 浮点类型

- `Float`: 32位浮点，精度约6位小数
- `Double`: 64位浮点，精度约15位小数

### 布尔类型

- `Bool`: 只有 `true` 和 `false` 两个值

### 字符串

- `String`: Unicode 字符串

### 元组

- 将多个值组合成复合值
- 可以命名元素
